# YEENKSLUXE storefront design system

## Direction

Lagos-born editorial streetwear: dark, direct, tactile and restrained. The interface should let the clothes and community imagery carry the energy.

## Foundations

- Ink: `#0b0b0a`
- Paper: `#f0ede6`
- Bright paper: `#faf8f3`
- Signal red: `#b72228`
- Highlight lime: `#d7ff38`
- Display: Cormorant Garamond
- Interface: DM Sans
- Content width: `1440px`

## Component principles

1. One dominant message per section.
2. Show one currency at a time.
3. Use actual product and community images; do not generate substitute garments.
4. Product cards use short names. Collection information is secondary.
5. Use motion only to clarify state or add quiet depth.
6. Every clickable element must be a button or link with a visible focus state.
7. Product facts and store policies must be confirmed before deployment.

## Image guidance

- Hero: landscape campaign image with negative space for copy.
- Product grid: consistent portrait crop, neutral background, front-first.
- Product details: front, back, artwork close-up, styled view.
- Community: candid images may vary, but use consistent colour grading.

## Before production

- Confirm delivery timing and free-delivery claim.
- Confirm the seven-day exchange policy.
- Replace approximate colour names with the official colourways.
- Add exact garment measurements for every release.
- Set the production domain as `metadataBase` in `src/app/layout.tsx`.
